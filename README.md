**MediLinks** is a patient-centric healthcare discovery and communication platform designed to streamline how individuals find verified doctors, explore medical specializations, and initiate care inquiries.

This repository holds the **Milestone 1 / Task 1** deliverables and architecture foundations.

## 🌟 Core Features (Milestone 1)

* **Doctor & Clinic Discovery:** Find nearby healthcare professionals across primary care, cardiology, pediatrics, and emergency services.
* **Modern Clinic Showcase:** Responsive hospital and clinic profiles with service breakdowns.
* **Patient Inquiry & Feedback:** Interactive contact and query validation forms.
* **Responsive Healthcare UI:** Mobile-first layout designed for accessibility and quick emergency lookups.

## 📁 Package Contents (`medinew.zip`)

```text
medinew/
├── index.html       # Primary landing page & doctor discovery showcase
├── about.html       # Clinic mission, verified medical specialists & values
├── contact.html     # Patient support, emergency hotlines & inquiry form
├── style.css        # Clean, accessible healthcare theme and layout
└── script.js       # Dynamic interactions, mobile navbar & form validation
```

## 🚀 How to Run & Extract

1. **Extract the archive:**
   Unzip `medinew.zip` to your preferred folder.
2. **Launch in browser:**
   Open `medinew/index.html` directly in your browser or run via Live Server in VS Code.
